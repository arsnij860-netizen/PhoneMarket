# PhoneMarket Tycoon — Android

Это Android-проект без Python и PySide6. Игра запускается внутри Android-приложения через встроенный WebView; игровые данные сохраняются локально на устройстве через localStorage. Интернет для игры не нужен.

## Как получить APK без установки Android Studio

1. Создай новый пустой репозиторий на GitHub.
2. Загрузи в репозиторий все файлы этой папки (включая скрытую папку `.github`).
3. Открой вкладку **Actions** и выбери workflow **Build Android APK**.
4. Нажми **Run workflow** и дождись зелёного статуса.
5. Открой завершённый запуск и скачай артефакт **PhoneMarketTycoon-APK**. Внутри будет `app-debug.apk`.
6. Перенеси APK на Android и установи. Если Android спросит разрешение на установку из этого источника, разреши его для приложения, которым открываешь файл.

## Сборка на компьютере с Android SDK

Нужны Java 17, Android SDK Platform 35 и Gradle 8.9. В корне проекта выполни:

```bash
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Примечания

- Это не Python-приложение: исходный игровой интерфейс переписан в HTML/CSS/JavaScript и встроен в Android оболочку на Java.
- Сборка workflow — debug APK для личной установки, не подписанный релиз для Google Play.
- Прогресс хранится в локальном хранилище приложения. Удаление приложения может удалить сохранение.
